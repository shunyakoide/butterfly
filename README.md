# butterfly

壁にとまる青いモルフォ蝶(Morpho peleides)を three.js の WebGPU で描くデモ。モデルファイルは使わず、形・模様・構造色・毛までコードで作っている。触ると飛び去り、少し違う色と模様になって戻ってくる。本物なのは蝶だけで、とまっている壁は光る線で描いた四角い柱の集まり。蝶の足元では柱の天面がそろって足場になり、離れるほどばらばらの深さへ沈んで、奥へ果てしなく続く暗い空間に溶ける。蝶が飛び去ると足場ごと沈み、戻るとせり上がる。もう一つの壁として、琥珀色の回路が層になって奥へ続き、光のパルスが走る壁も選べる。

## 動かし方

```bash
npm install
npm run dev
```

WebGPU に対応したブラウザ(Chrome / Edge / Safari 26 以降など)で開く。

## 操作

- 蝶をタップ: 飛び去る
- 視点は固定
- ドラッグ: 太陽の向き
- W: 壁を切り替え(柱 / 回路)

URL パラメータ: `?pose=open|closed`(止まっているときの翅)、`?sun=方位,仰角`(度)、`?wear=0..1`(翅の擦り切れ)、`?slow=0.1`(スローモーション)、`?wall=circuit`(回路の壁で始める)。

## ファイル

| ファイル | 中身 |
|---|---|
| `main.js` | シーン、壁、光、カメラ操作、飛び方 |
| `butterfly.js` | 蝶の組み立てと翅の動き |
| `wing.js` | 翅の形、翅脈、凹凸 |
| `pattern.js` | 翅の模様のパラメータと描画 |
| `morpho.js` | 青い構造色(鱗粉ごとの干渉反射)のマテリアル |
| `body.js` | 胴体、毛、複眼、触角、脚 |
| `rift.js` | 柱の壁と、その奥の空間 |
| `circuit.js` | 回路の壁 |
| `noise.js` | ノイズと乱数 |
| `refs.html` | 見比べ用の参照写真(Unsplash へのリンク。画像は含まない) |

## 素材

蝶を照らす空の光は Poly Haven の HDRI [garden_nook](https://polyhaven.com/a/garden_nook)(CC0)を実行時に読み込んでいる。
