# butterfly

壁にとまる青いモルフォ蝶を three.js の WebGPU で描くデモ。モデルファイルは使わず、形・模様・構造色・毛までコードで作っている。ページを開くたびに、モルフォ属の7種(peleides、menelaus、achilles、helenor、rhetenor、cypris、sulkowskyi)から1種を選び、表と裏の模様をその種らしく描く(翅と体の形は peleides のまま)。止まっている間は、4本の脚で歩いて太陽に背を向けるように向き直り、ときどき少し歩く(太陽をドラッグすると向き直る)。触ると飛び去り、少しして戻ってくる。本物なのは蝶だけで、とまっている壁は光る線で描いた四角い柱の集まり。蝶の足元では柱の天面がそろって足場になり、離れるほどばらばらの深さへ沈んで、奥へ果てしなく続く暗い空間に溶ける。蝶が飛び去ると足場ごと沈み、戻るとせり上がる。ほかに、琥珀色の回路が層になって奥へ続き光のパルスが走る壁と、銀白色のガラスの箱が重なった結晶のような壁も選べる。

## 動かし方

```bash
npm install
npm run dev
```

WebGPU に対応したブラウザ(Chrome / Edge / Safari 26 以降など)で開く。

## 操作

- 蝶をタップ: 飛び去る
- 視点は固定
- ドラッグ: 太陽の向き
- W: 壁を切り替え(柱 / 回路 / ガラス)
- E: 分析表示(蝶を追う点と線・数値、サーモ / X 線風の拡大枠、文字)
- D: 蝶の描き方を切り替え(緑の点描 / 青の網点 / 白地に黒のドット / クローム / ホログラム / 等高線 / サーモ / オフ)
- いつも出る演出: 飛び立つときに蝶がブロックに崩れて流れる、翅から舞い落ちながら瞬く、星形のきらめき(鱗粉)

URL パラメータ: `?pose=open|closed`(止まっているときの翅)、`?sun=方位,仰角`(度)、`?species=peleides|menelaus|achilles|helenor|rhetenor|cypris|sulkowskyi`(種を決めて開く)、`?wear=0..1`(翅の擦り切れ)、`?slow=0.1`(スローモーション)、`?wall=circuit|glass`(回路・ガラスの壁で始める)、`?fx=on`(分析表示をオンで始める)、`?print=dots|halftone|pixels|chrome|holo|topo|thermal`(プリント表示で始める)、`?perf`(fps と 1 コマの GPU 時間を左下に出す。`window.app` から各部分を切り替えて重さを比べられる)。

## ファイル

| ファイル | 中身 |
|---|---|
| `main.js` | シーン、壁、光、環境光、ポストエフェクト、操作、ループ |
| `flight.js` | 蝶のふるまい(止まる場所、壁の上の歩き、飛び立ちと戻り、翅の動き) |
| `butterfly.js` | 蝶の組み立てと翅の動き |
| `wing.js` | 翅の形、翅脈、凹凸 |
| `pattern.js` | 種ごとの翅の模様のパラメータと描画 |
| `morpho.js` | 青い構造色(鱗粉ごとの干渉反射)のマテリアル |
| `body.js` | 胴体、毛、複眼、触角、脚(関節で曲がる) |
| `rift.js` | 柱の壁と、その奥の空間 |
| `circuit.js` | 回路の壁 |
| `glass.js` | ガラスの壁 |
| `fx.js` | 分析表示のオーバーレイ |
| `digital.js` | 蝶の描き方の切り替え(D)と、飛び立ちの崩れ |
| `motion.js` | 翅から舞うきらめき(鱗粉) |
| `noise.js` | ノイズと乱数 |
| `refs.html` | 見比べ用の参照写真(Unsplash へのリンク。画像は含まない) |
